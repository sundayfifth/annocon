# ANNOCON

ปลั๊กอิน Figma สำหรับใส่โน้ตอธิบาย (**Annotate**) และลากเส้นเชื่อม layer (**Connect**)
แบบที่ผูกติดอยู่กับไฟล์จริง ไม่ใช่ overlay ชั่วคราวที่หายไปตอน export หรือ present —
เปิดไฟล์ที่ไหน เห็นครบทุกคนที่ไหน ไม่ต้องเปิด Dev Mode หรือสลับโหมดดูอะไรเป็นพิเศษ

## มีอะไรใหม่

ดูรายการทั้งหมดได้ที่ **[หน้า Releases](https://github.com/sundayfifth/annocon/releases)** —
ทุกเวอร์ชันเขียนไว้ว่าเปลี่ยนอะไร และมีไฟล์ให้โหลดพร้อมวิธีอัปเดต

## วิธีติดตั้ง

ทุกวิธีต้องมี **[Figma desktop app](https://www.figma.com/downloads/)** เท่านั้น
(ใช้ผ่านเว็บเบราว์เซอร์ไม่ได้ — ถ้าปกติเปิด Figma ผ่านเบราว์เซอร์อยู่ ต้องโหลดแอปนี้แยกก่อน)

### วิธีง่าย — ดาวน์โหลดไฟล์ที่ build ไว้แล้ว (แนะนำสำหรับคนในทีมที่แค่อยากลองใช้)

ไม่ต้องมี Node.js หรือ build เองเลย:

1. ไปที่ **[หน้า Releases](https://github.com/sundayfifth/annocon/releases/latest)**
   ดาวน์โหลด `annocon-plugin.zip`
2. แตกไฟล์ zip ออกมา (จะได้โฟลเดอร์ `annocon` ที่มี `manifest.json` กับโฟลเดอร์ `build/`
   อยู่ข้างใน) วางไว้ตรงไหนของเครื่องก็ได้ แค่**อย่าลบหรือย้ายโฟลเดอร์นี้ทีหลัง** เพราะ Figma
   จะจำ path นี้ไว้เปิดปลั๊กอินทุกครั้ง
3. เปิด Figma desktop app → เมนู **Plugins → Development → Import plugin from
   manifest…** → เลือกไฟล์ `manifest.json` ที่อยู่ในโฟลเดอร์ที่แตกออกมา

เท่านี้ก็ใช้งานได้เลย

### เคยติดตั้งเวอร์ชันเก่าไว้แล้ว — อัปเดตยังไง

**ไม่ต้อง import ใหม่ และไม่ต้องลบตัวเก่าทิ้ง** แค่เอาไฟล์ใหม่ไปทับที่เดิม:

1. โหลด `annocon-plugin.zip` ตัวล่าสุดจาก
   **[หน้า Releases](https://github.com/sundayfifth/annocon/releases/latest)** แล้วแตกไฟล์
2. เอาโฟลเดอร์ `annocon` ที่ได้ ไปวางทับโฟลเดอร์เดิมที่เคยแตกไว้ (ทับทั้งโฟลเดอร์ได้เลย)
3. ถ้าเปิดปลั๊กอินค้างอยู่ ปิดแล้วเปิดใหม่ — โค้ดใหม่จะถูกดึงมาใช้ทันที

**ต้องวางทับที่เดิมจริงๆ** เพราะ Figma จำ path ที่ import ไว้ครั้งแรก ถ้าเผลอวางที่ใหม่ ปลั๊กอิน
จะยังรันโค้ดเก่าจาก path เดิมอยู่ (กรณีนี้ให้ import จาก path ใหม่ แล้วลบตัวเก่าออกทาง
**Plugins → Development → Manage plugins…** จะได้ไม่มีสองอันซ้ำในเมนู)

ข้อมูลเดิมอยู่ครบ — โน้ต, category, เส้นเชื่อม และสไตล์ล่าสุดที่จำไว้ ไม่หายไปไหน เพราะทุกอย่าง
เก็บอยู่ในไฟล์ Figma กับตัวปลั๊กอินเอง ไม่ได้อยู่ในโฟลเดอร์ที่แตก zip

### วิธี build เอง (สำหรับคนที่จะแก้โค้ดต่อ)

ต้องมี [Node.js](https://nodejs.org) เวอร์ชัน 22 ขึ้นไปเพิ่มด้วย

```bash
git clone https://github.com/sundayfifth/annocon.git
cd annocon
npm install
npm run build
```

จากนั้นเปิด Figma desktop app → เมนู **Plugins → Development → Import plugin from
manifest…** → เลือกไฟล์ `manifest.json` ที่ถูกสร้างขึ้นในโฟลเดอร์นี้

ระหว่างพัฒนาต่อ ใช้ `npm run watch` ให้ build ใหม่อัตโนมัติทุกครั้งที่แก้โค้ด แล้วรัน
ปลั๊กอินใหม่ในหน้า Figma เพื่อดึงโค้ดล่าสุดมาใช้

> ปลั๊กอินนี้ยังไม่ได้เผยแพร่ขึ้น Figma Community เลยต้อง import เองผ่านเมนู Development
> ตามขั้นตอนข้างบน จะไม่เจอมันถ้าค้นหาในหน้า Community

## วิธีใช้งาน

เปิดปลั๊กอินจาก **Plugins → Development → ANNOCON → Annotate & Connect** ก่อน จากนั้นเลือก
ทำอย่างใดอย่างหนึ่งต่อไปนี้ได้เลย ไม่ต้องเรียงลำดับ:

### การ Annotate

เลือก layer 1 อัน → พิมพ์โน้ตในแท็บ Annotate → เลือก category (ถ้าต้องการ) → พิมพ์เสร็จ
คลิกออกจากช่อง จะเห็นการ์ดขึ้นบน canvas ทันที

แก้ทีหลัง: คลิกที่การ์ดบน canvas ได้เลย ปลั๊กอินจะเปิดโน้ตนั้นให้แก้ (ไม่ต้องย้อนไปคลิก layer
ต้นทาง) หรือดับเบิลคลิกที่การ์ดแล้วพิมพ์ทับตรงนั้นก็ได้ ปรับขนาดด้วยปุ่ม Small / Medium / Large
หรือลากขอบการ์ดเอง

### การ Connect

เลือก layer 2 อันพร้อมกัน (คลิกอันแรกก่อน แล้ว Shift/Cmd-คลิกอันที่สอง) ปลั๊กอินจะสร้าง
เส้นเชื่อมให้เอง แล้วเด้งไปแท็บ Connect ให้ปรับแต่งสไตล์ได้เลย

แก้ทีหลัง: คลิกที่เส้น หรือคลิกที่ป้ายกำกับบนเส้นก็ได้ ทั้งสองอย่างเปิดเส้นนั้นให้แก้

### จัดการ category

แท็บ Categories — เพิ่ม/แก้ชื่อ/เปลี่ยนสี/ลบได้ตามใจ

## ข้อควรระวัง

**ปลั๊กอินต้องเปิดอยู่ ระบบถึงจะทำงานแบบ real-time ได้** — นี่เป็นข้อจำกัดของแพลตฟอร์ม Figma
เอง ไม่ใช่ปลั๊กอินไหนก็ทำได้ทั้งนั้น: โค้ดปลั๊กอินจะทำงานได้เฉพาะตอนหน้าต่างปลั๊กอินเปิดค้างอยู่
(ต่อให้ไม่ได้โฟกัสหน้าต่างนั้นก็ยังนับว่า "เปิดอยู่") พอปิดปลั๊กอินจริงๆ (กดกากบาท หรือ Esc)
โค้ดจะหยุดทำงานทันที ไม่มีทางดักจับการขยับ/แก้ไข layer ได้เลยจนกว่าจะเปิดใหม่

ผลคือ:

- **ขยับ layer ที่มี annotate หรือ connector ผูกอยู่ ตอนปิดปลั๊กอิน** — เส้น/การ์ดจะ "ค้าง"
  อยู่ตำแหน่งเดิมชั่วคราว ไม่ได้พังถาวร แค่รอ sync รอบถัดไปเท่านั้น พอเปิดปลั๊กอินใหม่มันจะขยับตาม
  ให้ถูกต้องเองอัตโนมัติ หรือถ้าไม่อยากเปิดปลั๊กอินเต็มๆ ก็คลิกขวาบน canvas →
  **Plugins → ANNOCON → Re-sync this page** ได้เลย ไม่ต้องเปิดหน้าต่างปลั๊กอิน
- **การลบการ์ด Annotate** — ลบการ์ดบน canvas ได้ตลอดเวลา แต่การเคลียร์ข้อมูลที่ผูกไว้
  (เส้นประ + ข้อมูลโน้ต) ให้ครบจะเกิด**ทันที**ถ้าปลั๊กอินเปิดอยู่ ถ้าปิดอยู่ตอนลบ ต้องรอเปิดปลั๊กอิน
  อีกครั้ง (หรือกด Re-sync this page) ระบบถึงจะเคลียร์ให้ครบให้เอง — ไม่ต้องทำอะไรเพิ่มเติมเอง
  แค่รอ sync รอบหน้า
- **การลบเส้น Connector** — ลบได้เลยทันที **ไม่ว่าปลั๊กอินจะเปิดหรือปิดอยู่ก็ตาม** เพราะข้อมูล
  ทั้งหมดผูกอยู่กับตัวเส้นเองโดยตรง ลบเส้น = ข้อมูลหายไปพร้อมกันในตัว ไม่มีอะไรค้าง (ถ้าเส้นนั้น
  มีข้อความกำกับไว้ด้วย ป้ายข้อความจะถูกเก็บกวาดตอน sync รอบถัดไป)

## คำถามที่พบบ่อย

#### หาปลั๊กอินในเมนู Plugins ไม่เจอ

ต้องเป็นเมนู **Plugins → Development → ANNOCON** เท่านั้น — ไม่ใช่ Plugins ธรรมดาที่โชว์
ปลั๊กอินจาก Figma Community

ถ้ายังไม่เจอในเมนู Development แปลว่ายังไม่ได้ import ย้อนกลับไปทำตาม
[วิธีติดตั้ง](#วิธีติดตั้ง) ด้านบนก่อน

#### จะลบปลั๊กอินออกยังไง

1. **Plugins → Development → Manage plugins…**
2. ลบ ANNOCON ออกจากลิสต์
3. (ไม่บังคับ) ลบโฟลเดอร์ที่แตก zip ไว้ในเครื่องทิ้งด้วยก็ได้

#### ปลั๊กอินใช้ได้กับไฟล์ FigJam ไหม

ไม่ได้ — รองรับเฉพาะไฟล์ Design เท่านั้น
